# OpsGen trademarks

The code in this repository is licensed under [MIT](LICENSE): use it, change it, ship it. The license covers the code,
not the OpsGen name and logo. This page says how you can use them, so that people always
know what comes from the OpsGen project and what does not.

## You can

- Say what your work does with OpsGen: "made with OpsGen", "an OpsGen film", "works with OpsGen", "for the
  OpsGen format".
- Refer to OpsGen in articles, talks, tutorials, courses and videos.
- Fork this repository and keep the name while you work on changes you mean to send back.
- Redistribute unmodified releases under their own name.

## You can't, without written permission

- Name a modified version, a product, a hosted service or a company "OpsGen", or anything easily confused with it.
  A fork you publish as your own needs its own name.
- Use the OpsGen logo for your own product or service, or a logo that looks like it.
- Suggest that the OpsGen project made, endorses or supports your work when it does not.
- Use "openfilm" in a domain name, package name or account name in a way that looks official.

## Questions

Write to support@openfilm.dev. If you are not sure whether a use is fine, ask: most are.
