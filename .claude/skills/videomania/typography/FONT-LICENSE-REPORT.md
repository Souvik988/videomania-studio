## B. What each state means here

- **Impact → Impact**: Impact is installed on this machine and is used in place through CSS `local()`. The file is never copied into projects, deliveries or the repo. Elsewhere (cloud renders) the role falls back to Anton.
- **Snell Roundhand → Great Vibes**: Snell Roundhand is not installed here. Great Vibes (OFL) renders instead.
- **Rockwell → Arvo**: Rockwell is not installed here. Arvo (OFL) renders instead. Official purchase: https://www.myfonts.com/collections/rockwell-font-monotype-imaging
- **Helvetica → Inter**: Helvetica is not installed here. Inter (OFL) renders instead. Official purchase: https://www.monotype.com/fonts/helvetica-now
- **Garamond → EB Garamond**: Garamond is not installed here. EB Garamond (OFL) renders instead. Official purchase: https://www.myfonts.com/collections/garamond-font-monotype-imaging
- **Cormorant Garamond → Cormorant Garamond**: Cormorant Garamond is open source (OFL) and bundled: the exact font, free for commercial video.
- **Blacksword → Italianno**: Blacksword needs a commercial licence for ads and published videos. Not bought, not downloaded. Italianno (OFL) renders instead and is labelled as the fallback. Buy: https://youssef-habchi.com/license

## C. Script fallbacks (Hindi / Bengali)

- `bengali`: Hind Siliguri (SIL OFL 1.1) — installed
- `bengali_display`: Noto Sans Bengali (SIL OFL 1.1) — installed
