# Lessons (the brain's own rules)

Written by the teacher after films, read by the director before planning (`brain.py recall`). A lesson
starts as a bet (`brain.py bet add`) and is promoted here only after it won on two films. One loss sends
it back to a bet. The user's house rules, the Flow rules and the honesty rules are never edited from here.

Format: `- [L-n] <rule>. Evidence: <films>. Confidence: <wins>/<tries>.`

## Seed lessons (from the reference film and the user's notes, 2026-11-11 to 14)

- [L-1] Rhythm is chapters, not a clock: one take per idea of the voiceover (2.5–20 s) that changes inside the take on the word every 2–3 s (camera key, wash, act, word group); cut at chapter turns and in short bursts. Cutting every 2–3 s on a schedule feels forced. Evidence: reference reel cut map (16 cuts/min, one 22 s take), user note on director film v1 2026-11-14 ("feels like you were forcing"). Replaces the old 'world change every 8 s' rule. Confidence: confirmed by user.
- [L-2] Big square pixels read as cheap; fine pixels and layered depth read as made. Evidence: user note on voxel demo v2. Confidence: seed.
- [L-3] The cast must act, not present: at least three different actions and one impossible one per film. Evidence: reference reel, user note 2026-11-13. Confidence: seed.
- [L-4] Every shot needs a written reason ("why this, why now"); shots without one are the first to feel like filler. Evidence: user note 2026-11-14. Confidence: seed.
- [L-5] Sound must be measured, not assumed: music phrased by chapter with real drop-outs, ducking ≤ 6 dB, SFX hits level with the voice; match the reference's momentary-loudness p10/p50/p90 within 1.5 dB (scripts/sound_mix.py). Evidence: user could not hear v1's SFX or music, 2026-11-14. Confidence: confirmed by user.
- [L-6] Words go around the subject, never on it: frame the subject on a third, compose words on the other side with size, rotation, tilt and arc; keep backgrounds sharp unless blur is motivated. Evidence: user note on v1, 2026-11-14. Confidence: confirmed by user.
- [L-7] The host should be the creator as a mascot made from their photo (ChatGPT hero + two pose sheets, fine pixels about 260 px tall), and the pose must act the line: at a desk coding when the voice says he built it, holding the file when it names the skill. Code-drawn generic hosts read as not authentic. Evidence: user note on v2, 2026-11-14. Confidence: confirmed by user. Recipe: references/mascot-from-photo.md.
- [L-8] Score by meaning: map every song (music_map.py), cast one song per idea, enter on a downbeat at the chapter turn, no vocals under the voice, cut a song dead on a hard word, go a cappella 2-4 times, bookend the hook song, make literal jokes ("lower that voice" drops the music). Evidence: user note on v2, 2026-11-14. Confidence: confirmed by user. Recipe: references/audio-cinematography.md.
- [L-9] Open in a world that feels real (photoreal ChatGPT plate on a depth relief), then switch into the pixel world through a screen (pixelate). The jump between worlds is the hook's impact. Evidence: user note on the reference opening, 2026-11-14. Confidence: confirmed by user.
- [L-10] Asset-first: generate the real things (icons, app screens, objects, plates, the mascot) with the ChatGPT image bridge and use real footage (the film's own frames, earlier versions) BEFORE writing shots; code stitches, lights and animates them. A world drawn only by code reads synthetic; real pictures inside a pixel world give contrast. Evidence: user note on v3, 2026-11-14 ("rely on asset generation first, then do your things on it"). Confidence: confirmed by user. Gate: brain.py check (asset-first). Recipe: references/asset-first.md.
- [L-11] Picture mascots need volume: per-pose depth maps (pose_depth.py) make them a lit relief (2.5D) with a shadow side and recesses. Evidence: user note on v3, 2026-11-14 ("more depth, 2.5D, shadow"). Confidence: confirmed by user.
- [L-12] A hand-drawn marker layer (doodles: X, circle, underline, arrow, star) on top of the 3D world adds a human hand and makes a point land: cross out the thing being rejected, circle the thing to remember. Use 3-6 per film, on punch words. Evidence: v4, after the anidoodle repo (a style is a way of making marks). Confidence: RETIRED for this user - on v4 they said "remove that doodle thing"; use doodles only when asked.- [L-13] A reel of a landscape film is the film re-composed at 4:5 and padded to 9:16 with black bars (scripts/reel_frame.py). A 16:9 strip in a 9:16 frame reads "still landscape"; a full native 9:16 re-composition reads "transformed". Evidence: user notes on the v5 exports, 2026-11-14. Confidence: confirmed by user. Recipe: references/director-film-runbook.md Step 11.
- [L-14] A note on a delivered film changes only what it names: copy the shot list to a new version, edit the named things, keep everything else frame-identical. Evidence: user note on v4, 2026-11-14 ("don't just redesign the whole thing"). Confidence: confirmed by user.- [L-15] The skill is only as good as the weakest model that can run it: after any large change, run a short job (a 10 s clip) with the weaker model, write every stumble into the runbook's self-test log, and fix it in a script or the runbook, never only in the film. Evidence: Sonnet 5.5 test run, 2026-11-14 (found a lint-breaking backup file, a missing audio tag, no script-only start, no asset reuse step). Confidence: confirmed.- [L-16] The first second decides the view: frame 0 must be a full picture already distorting (a hook effect at full strength) with an ominous layered sound (transient + braam + sub), and the film must re-hook with an effect + sound every 3-7 s. Clean openings that fade in from black lose most viewers in the first second. Evidence: user's Instagram analytics, 2026-11-15 (65 % skip, 200 views vs the reference's 50K likes). Confidence: confirmed by user. Tool: fx_pass.py; gate: fx_pass.py check.
- [L-17] Splitting ONE photo into depth layers automatically (world_build.py) gives real parallax but seams and doubled edges on camera moves over ~40 voxels; a world the camera travels through should be generated as separate layers (clean background plate + transparent objects) with the image bridge and stacked at depths. SHARP (image -> Gaussian splats) needs >= 16 GB RAM. Evidence: world-test on this machine, 2026-11-15. Confidence: tested. Recipe: references/3d-worlds-without-blender.md.
- [L-18] An agent edits a timeline best through a compact read (`vm tl`: one line per track) and atomic JSON operations (`vm edit`), not by rewriting the project file or clicking: a whole 9-track film reads in ~1 KB and an edit that would break the film is refused before anything is written. The person watches in the editor, opened first. Evidence: OpsGen build, 2026-11-15. Confidence: tested. Recipe: references/opsgen.md.
