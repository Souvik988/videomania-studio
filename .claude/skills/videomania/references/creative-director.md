# Creative director

## Read the narration
Answer in `brief/concepts.md` with evidence → inference: genre, audience and sophistication,
promise, objection, emotional arc (with timecodes), CTA, the ONE idea to remember, delivery
(pace in words/s, pauses, energy). Mark assumptions. If a real company is named but no assets
were given, plan neutral visuals or visibly illustrative ones — never fake their UI or logo.

## Concepts
Write 2–3 genuinely different concepts (world, visual thesis, camera language, type system,
feasibility with the tools preflight actually reported, cost, risk). Choose by narrative fit,
originality, feasibility. Log `concept_selection` with scored options.

Useful structures, never forced: Problem → Friction → Transformation → Product → Benefit → CTA
(ads); Question → Evidence → Answer (explainers); Situation → Turn → Meaning (brand/documentary).

## Art direction (`brief/art_direction.md`)
- Visual thesis in one sentence.
- Palette: ground, ink, one or two accents with *rules* for when each may appear
  (e.g. "green only after the word green").
- Type system: display + label families (OFL fonts shipped with the project), sizes, tracking.
- Shape language, texture, light; motion personality (stop-start vs continuous, ease families).
- Sound palette.
- **Anti-patterns for this film** (specific, checkable).

## Style catalogue (pick by story, not habit)
| Mode | Good for | Tools |
|---|---|---|
| Continuous vector world (one camera, carried object) | process/flow ideas, SaaS, DevOps | HyperFrames SVG + render(t) |
| Kinetic typography | manifesto, quotes, hooks | HyperFrames text, masks |
| Editorial halftone collage | culture, opinion, history | needs image sources + licences |
| UI/product capture | real products (authorized) | Playwright capture → HyperFrames |
| Data/infographic | proof, numbers (sourced only) | SVG charts, count-ups |
| Painterly/character | narrative, warmth | p5/canvas seeded, original characters only |
| Cinematic AI plates | atmosphere, world-building | Google Flow MCP (when connected + budget) |
| 3D spatial | products, architecture | Three.js via HyperFrames, Blender for hero |

Hook: the first 1–3 s must be legible and tied to the first spoken idea — motion from frame 0,
a reason to keep watching by 2 s. Proof only from source data. No invented retention claims.
